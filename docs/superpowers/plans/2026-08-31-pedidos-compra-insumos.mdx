# Pedidos de compra de insumos — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Registrar pedidos de compra multi-item com data de chegada, projetar “a chegar” na sugestão (sem misturar no saldo físico) e mostrar selos A chegar/Atrasado na sugestão, no estoque e na lista de pedidos.

**Architecture:** Tabelas `insumo_pedido_compra` + itens. Status persistido `aberto|encerrado|cancelado`; atraso é derivado. `InsumoCompraProjecaoCalculator` simula saldo até H; o motor de sugestão passa a usar `qtd_bruta = meta − projetado_em_H`. Encerrar/cancelar não gera movimento em `insumo_saldos`. Badge puro + UI compartilhada nas três telas.

**Tech Stack:** Next.js 15 App Router, Supabase (migration + RLS), Vitest, Tailwind v4, Material Icons, design system Valepan.

**Spec:** `docs/superpowers/specs/2026-08-31-pedidos-compra-insumos-design.mdx`

## Global Constraints

- Arquivos ≤ 500 linhas; preferir < 400; classes SRP; funções < 40 linhas.
- RLS em toda tabela nova; DELETE físico só `(SELECT is_admin())`; SELECT/INSERT/UPDATE autenticados `USING (true)`.
- UI pt-BR, Material Icons (sem emoji estrutural), amber/stone, alvos ≥44px, Geist Mono/`tabular-nums` em quantidades.
- Pedido **não** escreve em `insumo_saldos` nem em `insumo_movimentos`.
- `qtd_bruta = max(0, meta − (saldo − demanda(H) + recebimentos_ate_H))` com `meta = demandaLead × 1,5`. Isto **substitui** `meta − estoque` da spec/plano de 12/08.
- H = `diasAteJanela + lead_time_dias`. Timezone `America/Sao_Paulo`.
- Demanda via `insumoCompraDiaOperacional` (pesos de dia útil), não `consumo × H` cego.
- Pedido atrasado: `aberto` e `data_chegada_prevista < hoje`; no motor `data_efetiva = max(prevista, data_referencia)`.
- Módulo auth: páginas GET `requireInternoModulo('interno_insumos', 'ler')`. Actions de salvar/encerrar/cancelar: `requireInternoModulo('interno_insumos', 'editar')` (igual a `ajustarInsumoSaldo`).
- Fora de escopo: NF×pedido, recebimento parcial, data por item, Omie pedido, WhatsApp.

const MEIO_DIA_SP = 'T12:00:00-03:00';

export function offsetDiasIso(dataReferencia: string, dataAlvo: string): number {
  const inicio = Date.parse(`${dataReferencia}${MEIO_DIA_SP}`);
  const alvo = Date.parse(`${dataAlvo}${MEIO_DIA_SP}`);
  return Math.round((alvo - inicio) / 86_400_000);
}

export function dataEfetivaIso(dataPrevista: string, dataReferencia: string): string {
  return dataPrevista < dataReferencia ? dataReferencia : dataPrevista;
}
```

  listPipelineAberto(dataReferencia: string): Promise<InsumoPedidoPipelineItem[]>;
  insert(input: {
    fornecedorNome: string;
    dataChegadaPrevista: string;
    observacao: string | null;
    criadoPor: string | null;
    itens: InsumoPedidoCompraItemInput[];
  }): Promise<InsumoPedidoCompraListItem>;
  replaceAberto(id: string, input: {
    fornecedorNome: string;
    dataChegadaPrevista: string;
    observacao: string | null;

  }): Promise<InsumoPedidoCompraListItem>;
  updateStatus(id: string, status: 'encerrado' | 'cancelado'): Promise<void>;
  countItensByInsumoId(insumoId: string): Promise<number>;
  listInsumoOpcoes(): Promise<Array<{ id: string; nome: string; unidade: string }>>;
}
```
