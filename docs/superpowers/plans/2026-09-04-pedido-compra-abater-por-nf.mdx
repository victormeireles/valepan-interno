# Pedido compra — abater na Entrada NF — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ao registrar uma nova entrada de NF (`entrada_nf` ou `resolucao_pendencia`), encerrar automaticamente um pedido de compra aberto elegível do mesmo insumo (janela hoje+3 dias).

**Architecture:** Domínio puro escolhe o pedido; repository lista candidatos; manager encerra; `InsumoEstoqueService.registrarEntrada` retorna se criou o movimento e dispara o abatimento — cobre webhook mapeado e resolução de pendência sem duplicar chamada.

**Tech Stack:** Next.js 15, Supabase, Vitest, TypeScript.

**Spec:** `docs/superpowers/specs/2026-09-04-pedido-compra-abater-por-nf-design.mdx`

## Global Constraints

- Arquivos ≤ 500 linhas; classes SRP; funções < 40 linhas.
- Não criar migration / coluna de vínculo NF↔pedido nesta fatia.
- Não checar quantidade; não parcial; encerrar no máximo **um** pedido por entrada criada.
- Janela: `data_chegada_prevista ≤ hoje (America/Sao_Paulo) + 3` (`JANELA_ABATIMENTO_PEDIDO_DIAS = 3`).
- Encerrar = `status = encerrado`; não mexe em saldo/movimentos.
- Só abater se o movimento de entrada foi **criado** (não reprocessamento idempotente).
- Reusar `addDaysIso` de `src/domain/insumos/insumo-compra-data-offset.ts`.

```ts
import { addDaysIso } from '@/domain/insumos/insumo-compra-data-offset';

export const JANELA_ABATIMENTO_PEDIDO_DIAS = 3;

export type InsumoPedidoAbaterCandidato = {
  id: string;
  dataChegadaPrevista: string;
  numero: number;
};

export function escolherPedidoParaAbaterPorNf(
  candidatos: InsumoPedidoAbaterCandidato[],
  hojeIso: string,
  janelaDias: number = JANELA_ABATIMENTO_PEDIDO_DIAS,
): string | null {
  const dataLimite = addDaysIso(hojeIso, janelaDias);
  const elegiveis = candidatos
    .filter((c) => c.dataChegadaPrevista <= dataLimite)
    .sort((a, b) => {
      if (a.dataChegadaPrevista !== b.dataChegadaPrevista) {
        return a.dataChegadaPrevista < b.dataChegadaPrevista ? -1 : 1;
      }
      return a.numero - b.numero;
    });
  return elegiveis[0]?.id ?? null;
}
```

  const pedidoIds = await this.listPedidoIdsByInsumoId(insumoId);

- [ ] **Step 4: Implement manager method**

```ts
async abaterPorEntradaNf(
  insumoId: string,
  hojeIso?: string,
): Promise<string | null> {
  const hoje = hojeIso ?? this.hojeSaoPauloIso();
  const candidatos = await this.repository.listAbertosParaAbaterPorInsumo(insumoId);
  const pedidoId = escolherPedidoParaAbaterPorNf(candidatos, hoje);
  if (!pedidoId) return null;
  await this.repository.updateStatus(pedidoId, 'encerrado');
  return pedidoId;
}
```

Extrair `hojeSaoPauloIso` igual ao do repository (copiar o `Intl.DateTimeFormat` private no manager, ou helper compartilhado mínimo em `insumo-compra-data-offset.ts` se quiser DRY — preferível:

```ts
// em insumo-compra-data-offset.ts
export function hojeSaoPauloIso(agora: Date = new Date()): string {
  const parts = new Intl.DateTimeFormat('en-US', {
    timeZone: 'America/Sao_Paulo',
    year: 'numeric',
    month: '2-digit',
    day: '2-digit',
  }).formatToParts(agora);
  const valueByType = new Map(parts.map((part) => [part.type, part.value]));
  return `${valueByType.get('year')}-${valueByType.get('month')}-${valueByType.get('day')}`;
}
```
