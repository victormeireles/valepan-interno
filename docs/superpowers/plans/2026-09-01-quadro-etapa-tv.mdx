# Quadros de etapa para TV — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Três telas de TV (`/painel/fermentacao|forno|embalagem`) com o card/gráfico do Fluxo da área, último lançamento e até 3 OPs seguintes, sem nav global.

**Architecture:** Páginas finas + `PainelEtapaTvPageClient` busca em paralelo `GET /api/painel/fluxo-processo/carga` e `GET /api/painel/<etapa>/carga`. Pickers de domínio escolhem último lote e próximas OPs. UI reusa `FluxoEtapaCard` (não selecionável), `FluxoBarrasHora` e `EtapaProductAccordion` (sem ações). Permissão `anyModulo(área | interno_painel, ler)`.

**Tech Stack:** Next.js 15 App Router, Vitest, Tailwind v4, Material Icons, design system Valepan.

**Spec:** `docs/superpowers/specs/2026-09-01-quadro-etapa-tv-design.mdx`

## Global Constraints

- Arquivos ≤ 500 linhas; preferir < 400; uma responsabilidade por arquivo; funções < 40 linhas.
- UI pt-BR, Material Icons (sem emoji estrutural), stone/amber, alvos ≥44px, Geist Mono/`tabular-nums` em quantidades.
- Unidade fixa: fermentação/forno = `lt`; embalagem = `cx`. Sem seletor.
- Cards de OP só leitura (sem lote/reabrir). Não alterar Painel Produção nem a página Fluxo.
- Refresh 60s em silêncio; falha no refresh não apaga a tela.
- Rotas estáticas (não `/painel/[etapa]`).
- Timezone `America/Sao_Paulo`.

export class PainelEtapaTvUltimoLotePicker {
  static fromLotes(lotes: PainelEtapaTvLoteFonte[]): PainelEtapaTvUltimoLote | null {
    if (lotes.length === 0) return null;
    return [...lotes].sort((a, b) => {
      const byTime = Date.parse(b.produzidoEm) - Date.parse(a.produzidoEm);
      if (byTime !== 0) return byTime;
      return b.loteId.localeCompare(a.loteId);
    })[0];
  }
}

```ts
export class PainelEtapaTvProximasOpsPicker {
  static pick(
    ops: PainelEtapaTvOpFonte[],
    excludeOrdemId: string | null,
    limite = 3,
  ): PainelEtapaTvOpFonte[] {
    const abertas = ops.filter((op) => !op.finalizada && op.ordemId !== excludeOrdemId);
    const parciais = abertas
      .filter((op) => op.produzido > 0)
      .sort((a, b) => a.ordemPlanejamento - b.ordemPlanejamento);
    const pendentes = abertas
      .filter((op) => op.produzido <= 0)
      .sort((a, b) => a.ordemPlanejamento - b.ordemPlanejamento);
    return [...parciais, ...pendentes].slice(0, limite);
  }
}
```
