# Cobertura de estoque no consumo de insumos — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Enriquecer a tela de Consumo de insumos com estoque atual, média, cobertura de dias e cobertura no pico, usando 4 semanas fechadas no padrão semanal.

**Architecture:** Ajustar o período padrão no `InsumoConsumoSemanalPeriodoBuilder`. Calcular métricas em classe de domínio pura (`InsumoConsumoCoberturaCalculator`). Na action, buscar saldos dos insumos retornados e enriquecer cada item. UI desktop/mobile troca Total por Estoque + métricas.

**Tech Stack:** Next.js App Router, React client components, Vitest, Tailwind, Material Icons, Supabase via `InsumoEstoqueRepository`.

**Spec:** `docs/superpowers/specs/2026-07-28-insumo-consumo-cobertura-estoque-design.mdx`

## Global Constraints

- Copy pt-BR operacional; headers UPPERCASE: `ESTOQUE`, `MÉDIA`, `COBERTURA`, `PICO`, `COB. PICO`.
- Semanal padrão: 4 semanas fechadas (dom–sáb), exclui semana corrente.
- Diária padrão: D-7 até D-1 (já existente).
- Fórmulas: semanal `cobertura = estoque * 7 / media`; diária `cobertura = estoque / media`; idem para pico.
- `media == 0` ou `pico == 0` → cobertura `null` → UI `—`; `estoque <= 0` → `0 d`.
- Dias: `Math.round`, mínimo 0.
- Não incluir insumos só com estoque e sem saída; sem migrations.
- Arquivos ≤500 linhas; classes/funções com SRP; commits por task.

- [ ] **Step 3: Implementar o calculator**

Criar `insumo-consumo-cobertura-calculator.ts`:

```ts
import type { InsumoConsumoVisualizacao } from './insumo-consumo-semanal-periodo';

export type InsumoConsumoCoberturaInput = {
  visualizacao: InsumoConsumoVisualizacao;
  estoqueAtual: number;
  consumos: number[];
};

export type InsumoConsumoCoberturaResult = {
  media: number;
  coberturaDias: number | null;
  pico: number;
  coberturaPicoDias: number | null;
};

export class InsumoConsumoCoberturaCalculator {
  calculate(input: InsumoConsumoCoberturaInput): InsumoConsumoCoberturaResult {
    const { consumos, estoqueAtual, visualizacao } = input;
    const n = consumos.length;
    const soma = consumos.reduce((acc, value) => acc + value, 0);
    const media = n === 0 ? 0 : soma / n;
    const pico = n === 0 ? 0 : Math.max(...consumos);

    return {
      media,
      pico,
      coberturaDias: this.coberturaDias(visualizacao, estoqueAtual, media),
      coberturaPicoDias: this.coberturaDias(visualizacao, estoqueAtual, pico),
    };
  }

  private coberturaDias(
    visualizacao: InsumoConsumoVisualizacao,
    estoqueAtual: number,
    consumoReferencia: number,
  ): number | null {
    if (consumoReferencia <= 0) return null;
    if (estoqueAtual <= 0) return 0;

    const consumoDiario =
      visualizacao === 'semanal' ? consumoReferencia / 7 : consumoReferencia;

    return Math.max(0, Math.round(estoqueAtual / consumoDiario));
  }
}

export const insumoConsumoCoberturaCalculator = new InsumoConsumoCoberturaCalculator();
```

async listQuantidadesByInsumoIds(insumoIds: string[]): Promise<Map<string, number>> {
  const result = new Map<string, number>();
  if (insumoIds.length === 0) return result;

  const { data, error } = await this.db
    .from('insumo_saldos')
    .select('insumo_id, quantidade')
    .in('insumo_id', insumoIds);

  if (error) {
    throw new Error(`Erro ao listar saldos de insumos: ${error.message}`);
  }

  for (const row of data ?? []) {
    result.set(row.insumo_id, Number(row.quantidade ?? 0));
  }

  return result;
}

export async function getInsumoConsumoSemanalPageData(input?: {

    };
  });

  return {
