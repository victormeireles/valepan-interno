# Rastreio de turnos na produção — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Carimbar turno 1/2/3 em cada lote novo de fermentação, forno e embalagem, com chip de turno ativo por etapa e prompt no + lote (primeiro do dia ou fora da janela).

**Architecture:** Domínio puro decide dia operacional, “dentro da janela” e se o + lote pergunta. Config passa a ter `config_operacao_turnos`; o snapshot ainda expõe os seis horários derivados (ritmo/fluxo intactos). `producao_turno_ativo` guarda o número confirmado por etapa. POST de lote recusa com 409 se o ativo do dia for inválido.

**Tech Stack:** TypeScript, Vitest, Next.js 15 App Router, React 19, Tailwind v4, Supabase (RLS), design system Valepan (pt-BR, Material Icons, Geist Mono).

**Spec:** `docs/superpowers/specs/2026-08-18-rastreio-turnos-producao-design.mdx`

## Global Constraints

- Arquivos ≤ 500 linhas; quebrar ao se aproximar de 400. Funções < 40 linhas. SRP por classe/arquivo.
- Relógio e dia operacional: `America/Sao_Paulo`. Reusar `brazilClockUtcMs`, `getBrazilDateISOFromInstant`, `addCalendarDaysISO`, `toMinutesFromClock`, `janelaDurationMinutes`.
- Identidade v1 = número do turno. Sem pessoa, PIN, `usuario_id` no lote.
- Ritmo/fluxo/estimativa **não** leem a tabela de turnos; só os seis campos derivados do snapshot.
- T1 obrigatório por etapa; T2/T3 em sequência; vão ok; sobreposição inválida; fronteira `fim(N)=início(N+1)` ok; instante da fronteira pertence ao seguinte (`[inicio, fim)`).
- Copy pt-BR da spec: `Definir turno`, `Qual turno?`, `Ainda é o Nº turno?`, `Continuar no Nº`, `Trocar para o Mº`, `Não foi possível trocar o turno.`
- PUT do ativo: `/api/producao/{fermentacao|forno|embalagem}/turno-ativo` (prefixo já gated no middleware; não usar URL única da spec).
- Testes: Vitest (`npm test -- <arquivo>`). Sem RTL/E2E: estados do sheet via função pura.
- Commits: incluir no passo; se a sessão não pediu commit, pular o `git commit`.

import { toMinutesFromClock } from '@/domain/painel-producao/painel-producao-time';

export function isClockInJanela(agoraMin: number, inicio: string, fim: string): boolean {
  const ini = toMinutesFromClock(inicio);
  const end = toMinutesFromClock(fim);
  if (end === ini) return false;
  if (end > ini) return agoraMin >= ini && agoraMin < end;
  return agoraMin >= ini || agoraMin < end;
}
```

export function brazilClockMinutes(now: Date): number {
  const parts = new Intl.DateTimeFormat('en-GB', {
    timeZone: 'America/Sao_Paulo',
    hour: '2-digit',
    minute: '2-digit',
    hourCycle: 'h23',
  }).formatToParts(now);
  const hour = Number(parts.find((p) => p.type === 'hour')?.value);
  const minute = Number(parts.find((p) => p.type === 'minute')?.value);
  return hour * 60 + minute;
}
```

```typescript
export type TurnoSheetModel = {
  title: string;
  actions: Array<{ numero: ProducaoTurnoNumero; label: string; primary: boolean }>;
};

export function buildTurnoSheetModel(
  decision: ProducaoTurnoPromptDecision,
  turnos: ProducaoTurnoCadastrado[],
): TurnoSheetModel | null {
  if (decision.kind === 'nenhum') return null;
  if (decision.kind === 'definir') {
    return {
      title: 'Qual turno?',
      actions: turnos.map((t) => ({
        numero: t.numero,
        label: `Turno ${t.numero}`,
        primary: false,
      })),
    };
  }
  const n = decision.numeroAtivo!;
  const actions: TurnoSheetModel['actions'] = [
    { numero: n, label: `Continuar no ${n}º`, primary: false },
  ];
  if (decision.turnoVigente && decision.turnoVigente !== n) {
    actions.push({
      numero: decision.turnoVigente,
      label: `Trocar para o ${decision.turnoVigente}º`,
      primary: true,
    });
  } else {
    for (const t of turnos) {
      if (t.numero === n) continue;
      actions.push({ numero: t.numero, label: `Trocar para o ${t.numero}º`, primary: false });
    }
  }
  return { title: `Ainda é o ${n}º turno?`, actions };
}
```
