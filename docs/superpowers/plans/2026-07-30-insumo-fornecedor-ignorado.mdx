# Fornecedores ignorados no mapeamento de insumos — Plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Permitir marcar fornecedores por CNPJ para sempre ignorar no mapeamento de insumos (pendências atuais + futuras), com tela em Config para desmarcar e opcionalmente restaurar.

**Architecture:** Tabela `insumo_fornecedor_ignorado` + Repository/Manager. O processor de recebimento consulta a lista antes de criar pendência. A fila de mapeamento oferece “só este produto” vs “tudo deste fornecedor”. Config lista e desmarca. CNPJ sempre normalizado (só dígitos).

**Tech Stack:** Next.js App Router, Supabase (migration + RLS), Vitest, Tailwind v4, componentes UI existentes (`Button`, `Card`, padrões de dialog do app).

**Spec:** `docs/superpowers/specs/2026-07-30-insumo-fornecedor-ignorado-design.mdx`

```sql
CREATE TABLE IF NOT EXISTS public.insumo_fornecedor_ignorado (
  id uuid PRIMARY KEY DEFAULT gen_random_uuid(),
  empresa_id uuid NOT NULL REFERENCES public.empresas(id),
  fornecedor_cnpj text NOT NULL,
  fornecedor_nome text,

  criado_por uuid REFERENCES auth.users(id),

CREATE POLICY insumo_fornecedor_ignorado_delete
```

```ts
export function normalizarCnpj(value: string | null | undefined): string | null {
  if (!value?.trim()) return null;
  const digits = value.replace(/\D/g, '');
  return digits.length === 14 ? digits : null;
}

export function isCnpjValido(digits: string | null | undefined): digits is string {
  return typeof digits === 'string' && /^[0-9]{14}$/.test(digits);
}

export function formatarCnpj(digits: string): string {
  const d = digits.replace(/\D/g, '');
  if (d.length !== 14) return digits;
  return `${d.slice(0, 2)}.${d.slice(2, 5)}.${d.slice(5, 8)}/${d.slice(8, 12)}-${d.slice(12)}`;
}
```

```ts
// Métodos essenciais (esqueleto)
async existsByCnpj(empresaId: string, cnpjDigits: string): Promise<boolean> {
  const { count, error } = await this.db
    .from('insumo_fornecedor_ignorado')
    .select('id', { count: 'exact', head: true })
    .eq('empresa_id', empresaId)
    .eq('fornecedor_cnpj', cnpjDigits);
  if (error) throw new Error(`Erro ao verificar fornecedor ignorado: ${error.message}`);
  return (count ?? 0) > 0;
}

async upsert(input: {
  empresaId: string;
  cnpjDigits: string;
  nome?: string | null;
  razao?: string | null;
  criadoPor?: string | null;
}): Promise<InsumoFornecedorIgnoradoRow> {
  const { data, error } = await this.db
    .from('insumo_fornecedor_ignorado')
    .upsert(
      {
        empresa_id: input.empresaId,
        fornecedor_cnpj: input.cnpjDigits,
        fornecedor_nome: input.nome ?? null,
        fornecedor_razao_social: input.razao ?? null,
        criado_por: input.criadoPor ?? null,
      },
      { onConflict: 'empresa_id,fornecedor_cnpj' },
    )
    .select()
    .single();
  if (error) throw new Error(`Erro ao marcar fornecedor ignorado: ${error.message}`);
  return data as InsumoFornecedorIgnoradoRow;
}
```

- Create: `src/app/actions/insumo-fornecedor-ignorado-actions.ts`

**Interfaces:**
- Produces:
  - `listarFornecedoresIgnorados(): Promise<InsumoFornecedorIgnoradoRow[]>`
  - `marcarFornecedorIgnorado(input): Promise<{ success; pendenciasIgnoradas?; error? }>`
  - `desmarcarFornecedorIgnorado(input): Promise<{ success; pendenciasRestauradas?; error? }>`

- [ ] **Step 1: Criar actions com `'use server'`**

```ts
'use server';

import { revalidatePath } from 'next/cache';
import { insumoFornecedorIgnoradoRepository } from '@/data/insumos/InsumoFornecedorIgnoradoRepository';
import { insumoFornecedorIgnoradoManager } from '@/lib/services/insumo-fornecedor-ignorado-manager';

const REVALIDATE = ['/mapeamento-insumos', '/config/fornecedores-insumos', '/estoque-insumos'] as const;

function revalidate() {
  for (const path of REVALIDATE) revalidatePath(path);
}

export async function listarFornecedoresIgnorados() {
  return insumoFornecedorIgnoradoRepository.listAll();
}

export async function marcarFornecedorIgnorado(input: {
  empresaId: string;
  cnpj: string;
  nome?: string | null;
  razao?: string | null;
}) {
  try {
    const result = await insumoFornecedorIgnoradoManager.marcarFornecedor(input);
    revalidate();
    return { success: true as const, ...result };
  } catch (error) {
    const message = error instanceof Error ? error.message : 'Erro ao marcar fornecedor';
    return { success: false as const, error: message };
  }
}

export async function desmarcarFornecedorIgnorado(input: {
  empresaId: string;
  cnpj: string;
  restaurarPendencias: boolean;
}) {
  try {
    const result = await insumoFornecedorIgnoradoManager.desmarcarFornecedor(input);
    revalidate();
    return { success: true as const, ...result };
  } catch (error) {
    const message = error instanceof Error ? error.message : 'Erro ao desmarcar fornecedor';
    return { success: false as const, error: message };
  }
}
```
