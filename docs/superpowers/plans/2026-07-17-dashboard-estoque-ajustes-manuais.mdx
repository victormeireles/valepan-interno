# Dashboard Estoque — Ajustes Manuais Globais Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Substituir “Novo estoque” por um modal global de ajustes manuais (data/hora, tipo, produto, antes → depois) no dashboard de estoque.

**Architecture:** Reutilizar `GET /api/estoque/movimentos?origem=ajuste_manual` sem endpoint novo. Derivar “estoque antes” com `calcularSaldoAntes(saldo, delta)`. Novos componentes `StockManualAdjustmentsDialog` + `StockManualAdjustmentList`; toolbar e empty-state atualizados; `NewStockDialog` removido. Histórico por produto permanece intacto.

**Tech Stack:** Next.js App Router, React client components, Vitest, Tailwind, Material Icons, helpers existentes em `estoque-date-range` e `quantidade-formatter`.

**Spec:** `docs/superpowers/specs/2026-07-17-dashboard-estoque-ajustes-manuais-design.mdx`

## Global Constraints

- Copy pt-BR operacional; botão **“Ajustes manuais”**; empty state sem CTA de criar estoque.
- Botão da toolbar: variante **secondary** (não primary/âmbar); ícone Material `history`; `aria-label="Ver ajustes manuais"`.
- Modal: padrão Hoje; atalhos Hoje · Ontem · 7 dias; `limit=100`; lista mais recente no topo.
- Campos por linha: data/hora · tipo de estoque · produto · antes → depois.
- `calcularSaldoAntes` **não** aplica clamp a zero.
- Não alterar `StockHistoryDialog` / timeline por produto.
- Arquivos ≤500 linhas; funções focadas; sem autor do ajuste / CSV / paginação extra.
- Commits frequentes por task; mensagens em inglês imperativo curto ou pt-BR estilo do repo.

```ts
export function calcularSaldoAntes(
  saldoDepois: Quantidade,
  delta: Quantidade,
): Quantidade {
  return {
    caixas: saldoDepois.caixas - (delta.caixas || 0),
    pacotes: saldoDepois.pacotes - (delta.pacotes || 0),
    unidades: saldoDepois.unidades - (delta.unidades || 0),
    kg: parseFloat(
      ((saldoDepois.kg || 0) - (delta.kg || 0)).toFixed(3),
    ),
  };
}
```

```tsx
'use client';

import type { EstoqueMovimentoRecord } from '@/domain/types/estoque-db';
import { calcularSaldoAntes } from '@/domain/estoque/quantidade-calculo';
import { formatQuantidade } from '@/lib/utils/quantidade-formatter';

export type StockManualAdjustmentListProps = {
  movimentos: EstoqueMovimentoRecord[];
  showDateOnTime?: boolean;
};

function formatAdjustmentTime(iso: string, showDate: boolean): string {
  const date = new Date(iso);
  const time = date.toLocaleTimeString('pt-BR', {
    hour: '2-digit',
    minute: '2-digit',
  });
  if (!showDate) return time;
  const day = date.toLocaleDateString('pt-BR', {
    day: '2-digit',
    month: '2-digit',
  });
  return `${day} · ${time}`;
}

export function StockManualAdjustmentList({
  movimentos,
  showDateOnTime = false,
}: StockManualAdjustmentListProps) {
  return (
    <ol className="space-y-2" aria-label="Lista de ajustes manuais">
      {movimentos.map((mov) => {
        const antes = calcularSaldoAntes(mov.saldo, mov.delta);
        return (
          <li
            key={mov.id}
            className="rounded-xl border border-stone-200 bg-white px-3 py-2.5 shadow-sm"
          >
            <time
              className="text-sm font-semibold tabular-nums text-stone-900"
              dateTime={mov.createdAt}
            >
              {formatAdjustmentTime(mov.createdAt, showDateOnTime)}
            </time>
            <p className="mt-1 text-sm text-stone-700">
              <span className="font-medium">{mov.tipoEstoqueNome}</span>
              <span className="text-stone-400"> · </span>
              <span>{mov.produtoNome}</span>
            </p>
            <p className="mt-1.5 text-sm tabular-nums text-stone-800">
              <span className="text-xs font-medium uppercase tracking-wide text-stone-500">
                Antes
              </span>{' '}
              <span className="font-semibold">{formatQuantidade(antes)}</span>
              <span className="mx-1.5 text-stone-400" aria-hidden="true">
                →
              </span>
              <span className="text-xs font-medium uppercase tracking-wide text-stone-500">
                Depois
              </span>{' '}
              <span className="font-semibold">{formatQuantidade(mov.saldo)}</span>
            </p>
          </li>
        );
      })}
    </ol>
  );
}
```
