# Sugestão de compras — ações na linha Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Na `/sugestao-compras`, permitir cadastrar regra ao clicar em insumos `sem_regra`, ajustar estoque com o modal existente em qualquer linha, e exibir cobertura em dias inteiros.

**Architecture:** Estado e modais ficam em `InsumoCompraSugestaoClient`. Tabela/lista/mobile recebem callbacks. Reutiliza `InsumoRegraCompraFormModal` e `InsumoAjusteModal`. Cobertura arredondada em `formatCoberturaDias`. Sem novos endpoints.

**Tech Stack:** Next.js App Router, React client components, Vitest, Tailwind v4, Material Icons, design system Valepan.

**Spec:** `docs/superpowers/specs/2026-08-12-sugestao-compras-acoes-linha-design.mdx`

## Global Constraints

- Arquivos ≤ 500 linhas; preferir < 400; classes/componentes com SRP; funções < 40 linhas.
- UI pt-BR, Material Icons (sem emoji estrutural), amber/stone, alvos ≥44px, Geist Mono/`tabular-nums` em quantidades.
- Focus ring amber-500; press feedback 120–180ms; não depender só de hover.
- Nome clicável **somente** quando `status === 'sem_regra'`; estoque clicável **sempre**.
- Sem coluna nova de ações; sem editar regra já existente nesta tela; sem histórico nesta tela.
- Após salvar: toast + `router.refresh()`; no ajuste, atualizar estoque da linha no estado local antes do refresh.
- Não alterar contratos de API além do necessário em `InsumoAjusteModal.onSaved` (passar `novoSaldo`).

- [ ] **Step 2: Criar trigger de regra**

```tsx
'use client';

import type { ReactNode } from 'react';
import type { InsumoCompraSugestaoLinha } from '@/lib/services/insumo-compra-sugestao-service';

type Props = {
  item: InsumoCompraSugestaoLinha;
  onCadastrarRegra: (item: InsumoCompraSugestaoLinha) => void;
  children: ReactNode;
  className?: string;
};

export default function InsumoCompraSugestaoRegraTrigger({
  item,
  onCadastrarRegra,
  children,
  className = '',
}: Props) {
  if (item.status !== 'sem_regra') {
    return <div className={className}>{children}</div>;
  }

  return (
    <button
      type="button"
      onClick={() => onCadastrarRegra(item)}
      aria-label={`Cadastrar regra de ${item.nome}`}
      className={[
        'inline-flex min-h-11 w-full items-start gap-1.5 rounded-xl text-left',
        'transition-colors duration-150 hover:bg-amber-50',
        'focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-amber-500 focus-visible:ring-offset-2',
        className,
      ].join(' ')}
    >
      <span className="material-icons mt-0.5 text-base text-amber-700" aria-hidden="true">
        rule
      </span>
      <span className="min-w-0 flex-1 text-amber-900">{children}</span>
    </button>
  );
}
```

- [ ] **Step 2: Helpers de mapeamento e handlers**

```tsx
function toRegraConfig(item: InsumoCompraSugestaoLinha): InsumoCompraRegraConfig {
  return {
    insumoId: item.insumoId,
    nome: item.nome,
    unidade: item.unidade,
    regra: null,
    distribuidores: [],
  };
}

function toSaldoDetalhes(item: InsumoCompraSugestaoLinha): InsumoSaldoComDetalhes {
  return {
    insumoId: item.insumoId,
    nome: item.nome,
    unidadeResumida: item.unidade,
    quantidade: item.estoque,
    custoUnitario: 0,
    ultimaEntradaEm: null,
  };
}

const handleCadastrarRegra = (item: InsumoCompraSugestaoLinha) => {
  setRegraTarget(toRegraConfig(item));
};

const handleAjustarEstoque = (item: InsumoCompraSugestaoLinha) => {
  setAjusteTarget(toSaldoDetalhes(item));
};

const handleRegraSaved = () => {
  setRegraTarget(null);
  setToast('Regra salva.');
  router.refresh();
};

const handleAjusteSaved = (novoSaldo: number) => {
  if (ajusteTarget) {
    setItens((atuais) =>
      atuais.map((linha) =>
        linha.insumoId === ajusteTarget.insumoId
          ? { ...linha, estoque: novoSaldo }
          : linha,
      ),
    );
  }
  setAjusteTarget(null);
  setToast('Saldo ajustado com sucesso');
  router.refresh();
};
```
