# Embalado no fluxo: OPs do dia vs OP anterior — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** O tile **Embalado** em Pães em trânsito mostra o volume casado das OPs do dia; lotes do dia cuja OP é de outra data vão para a linha `{n} de OP de DD/MM` e para uma segunda zona da lista; resfriando desconta o embalado real da OP.

**Architecture:** Trocar `FluxoFilasFifoEmb` por `FluxoFilasEmbPorOp` (soma por `ordemProducaoId`). O builder classifica eventos em `op_do_dia` / `op_anterior` / `sem_op`. O service passa a copiar `ordemProducaoId` nos eventos de embalagem e envia OPs extra (lote hoje, `dataProducao ≠ dia`). UI reutiliza o idioma já usado nos cards de etapa.

**Tech Stack:** TypeScript, Vitest, Next.js 15 App Router, React 19, Tailwind v4, design system Valepan.

**Spec:** `docs/superpowers/specs/2026-08-18-fluxo-embalado-op-dia-design.mdx`

```ts
function montarResumo(items: FluxoFilaItem[]): FluxoFilaResumo {
  const totalUn = items
    .filter((i) => i.origem === 'op_do_dia')
    .reduce((t, i) => t + i.volumeUn, 0);
  const anteriorUn = items
    .filter((i) => i.origem !== 'op_do_dia')
    .reduce((t, i) => t + i.volumeUn, 0);
  const presoUn = items.filter((i) => i.preso).reduce((t, i) => t + i.volumeUn, 0);
  return { totalUn, anteriorUn, presoUn, items };
}
```

```ts
export class FluxoFilasBuilder {
  constructor(
    private readonly embPorOp = new FluxoFilasEmbPorOp(),
    private readonly loteSaldo = new FluxoFilasLoteSaldo(),
  ) {}

  build(input: FluxoFilasBuilderInput): FluxoFilasDia | null {
    if (input.ops.length === 0) return null;
    const ops = [...input.ops].sort((a, b) => a.ordemPlanejamento - b.ordemPlanejamento);
    const aloc = this.embPorOp.alocar(input.eventosEmb);
    const idsDia = new Set(ops.map((o) => o.id));
    const opsAntById = new Map(input.opsAnteriores.map((o) => [o.id, o]));

    // aProduzir / fermentando / resfriando: loop só em `ops` (dia)
    // resfriando: loteSaldo.restantes(fornoDaOp, aloc.unPorOp.get(op.id) ?? 0)
    // embalado zona 1: para cada op do dia com un > 0, item origem op_do_dia
    // embalado zona 2: para cada opsAnteriores com un > 0, origem op_anterior
    // embalado sem_op: aloc.semOpPorProduto → item sintético (id '', ordemPlanejamento 0, origem sem_op)
```
