# Controle de Acesso Interno Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fechar o Valepan Interno com login (magic link / NextAuth), porta de entrada por módulos `interno_*` e gates por área, consumindo a ACL já existente no Pedidos.

**Architecture:** NextAuth fino no Interno (sessão/cookie próprios); `UsuarioAuthzLoader` lê `usuarios` + identidades + perfis no banco compartilhado; `InternoAccessManager` + `InternoRouteAccessMap` protegem middleware, páginas e server actions; admin de usuários continua só no Pedidos.

**Tech Stack:** Next.js 15, React 19, NextAuth v5 (`next-auth@5`), `@auth/supabase-adapter`, Resend (magic link), Supabase JS (service role), Vitest, TypeScript.

**Spec:** `docs/superpowers/specs/2026-08-10-controle-acesso-interno-design.mdx`

## Global Constraints

- Arquivos &lt; 500 linhas; classes com SRP; pt-BR na UI.
- Não copiar o monólito `lib/auth/*` do Pedidos (cobranças, vendedor, etc.).
- Não criar painel de usuários/ACL no Interno.
- APIs `/api/public/*` e `/api/cron/*` permanecem com API key / `CRON_SECRET` (sem sessão).
- Service role após gate de app; RLS fino = fora deste plano.
- PIN/SSO/WhatsApp OTP = fora deste plano.
- Testes com Vitest: `npm test -- <path>`.
- Spec de níveis de página: chão = `editar`; painel/estoque TV = `ler`; config = `administrar`; ordens/etiquetas/insumos página = `ler` (writes nas actions = `editar`).

// src/lib/auth/interno-modulos-catalog.ts
export const MODULOS_INTERNO = [
  'interno_fermentacao',
  'interno_forno',
  'interno_embalagem',
  'interno_saidas',
  'interno_painel',
  'interno_ordens',
  'interno_etiquetas',
  'interno_insumos',
  'interno_estoque',
  'interno_config',
] as const;

export type InternoModuloId = (typeof MODULOS_INTERNO)[number];

export const NIVEIS = ['ler', 'editar', 'administrar'] as const;
export type NivelModulo = (typeof NIVEIS)[number];

export const NIVEL_ORDEM: Record<NivelModulo, number> = {
  ler: 1,
  editar: 2,
  administrar: 3,
};

export function isModuloInterno(value: string): value is InternoModuloId {
  return (MODULOS_INTERNO as readonly string[]).includes(value);
}

export function nivelAtende(
  atual: NivelModulo | undefined,
  minimo: NivelModulo,
): boolean {
  if (!atual) return false;
  return NIVEL_ORDEM[atual] >= NIVEL_ORDEM[minimo];
}
```

// perfil-modulos-resolver.ts — resolve max; descartar módulos !isModuloInterno
// interno-access-manager.ts
export class InternoAccessError extends Error {
  readonly code = 'INTERNO_FORBIDDEN' as const;
  constructor(message: string) {
    super(message);
    this.name = 'InternoAccessError';
  }
}

export type UsuarioAuthzSnapshot = {
  isSystemOwner: boolean;
  identidades: string[];
  modulosEfetivos: Partial<Record<InternoModuloId, NivelModulo>>;
};

export class InternoAccessManager {
  podeAcessarApp(snap: UsuarioAuthzSnapshot): boolean {
    if (snap.isSystemOwner) return true;
    return Object.keys(snap.modulosEfetivos).some((k) => isModuloInterno(k));
  }

  temModulo(
    snap: UsuarioAuthzSnapshot,
    modulo: InternoModuloId,
    minimo: NivelModulo,
  ): boolean {
    if (snap.isSystemOwner) return true;
    return nivelAtende(snap.modulosEfetivos[modulo], minimo);
  }

  requireModulo(
    snap: UsuarioAuthzSnapshot,
    modulo: InternoModuloId,
    minimo: NivelModulo,
  ): void {
    if (!this.temModulo(snap, modulo, minimo)) {
      throw new InternoAccessError(`Sem permissão: ${modulo} (${minimo})`);
    }
  }
}
```

// require-interno-modulo.ts
export async function requireInternoModulo(
  modulo: InternoModuloId,
  minimo: NivelModulo,
): Promise<UsuarioAuthzSnapshot> {
  const session = await auth();
  if (!session?.user?.id) redirect('/login');
  const snap: UsuarioAuthzSnapshot = {
    isSystemOwner: session.user.isSystemOwner,
    identidades: ['interno'],
    modulosEfetivos: session.user.modulosEfetivos,
  };
  new InternoAccessManager().requireModulo(snap, modulo, minimo);
  return snap;
}
